# SoilScope

SoilScope es un sistema para monitorear parámetros climáticos y de humedad en cultivos.

## Estructura del Proyecto

- `main.py`: Archivo principal que inicia la aplicación.
- `resources/`: Contiene recursos estáticos como estilos, imágenes y datos simulados.
- `soilscope/`: Carpeta con la lógica y pantallas del proyecto.

## Instalación

1. Instala las dependencias:
   ```bash
   pip install -r requirements.txt
   ```

2. Ejecuta la aplicación:
   ```bash
   python main.py
   ```

## Dependencias

- PyQt5
- pyqtgraph
